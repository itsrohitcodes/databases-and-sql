# Database and SQL

A collection of SQL notes, queries, practice exercises, and projects based on my database learning syllabus.

## 📚 Syllabus and Topics

### 1. Database Essentials
- Introduction to databases and DBMS
- Database tables, rows, and columns
- Data types
- Primary keys and foreign keys
- Database relationships

### 2. Data Definition Language (DDL)
- `CREATE`
- `ALTER`
- `DROP`
- `TRUNCATE`

### 3. DML – Managing Data
- `INSERT`
- `UPDATE`
- `DELETE`

### 4. DQL – Retrieving and Filtering Data
- `SELECT`
- `WHERE`
- `DISTINCT`
- `ORDER BY`
- `LIMIT`
- Filtering with comparison and logical operators

### 5. SQL Functions
- String functions
- Numeric functions
- Date and time functions
- NULL-handling functions
- Type conversion functions

### 6. Aggregate Queries
- `COUNT()`
- `SUM()`
- `AVG()`
- `MIN()`
- `MAX()`
- `GROUP BY`
- `HAVING`

### 7. Working with Multiple Tables
- Table relationships
- `INNER JOIN`
- `LEFT JOIN`
- `RIGHT JOIN`
- Self joins
- Subqueries

### 8. Developer Querying Skills
- Complex SQL queries
- Conditional expressions using `CASE`
- Subqueries and nested queries
- Common Table Expressions (CTEs)
- Query debugging and optimization basics

### 9. Developer Database Essentials
- Database constraints
- Indexes
- Views
- Transactions
- Normalization
- Database design and integrity

## 🛠️ Technologies
